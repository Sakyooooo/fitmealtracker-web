# 06. チェックリスト

ui-ux-pro-max-skill の「納品前チェックリスト」を土台に、FitMealTracker 用に拡張したもの。
**コピーして PR の説明に貼り、チェックして出す。**

---

## A. 設計前（コードを書く前 — AGENTS.md の「設計案を提示」に対応）

- [ ] この画面で **ユーザーが達成したい 1 つのこと** を 1 行で書いた
- [ ] その動線は **何タップで終わるか** を数えた（食事記録は 3 タップ以内が目標）
- [ ] 既存の画面・コンポーネントで代用できないか確認した（新規作成を最後の手段にする）
- [ ] 使う色・文字サイズ・角丸・余白を **02-design-system.md のトークンから選んだ**（新しい値を作っていない）
- [ ] **空・1 件・大量・エラー・オフライン・読み込み中**の 6 状態をどう見せるか決めた
- [ ] モバイル（375px）でのレイアウトを先に決めた（デスクトップは後）

---

## B. 実装中

### 構造

- [ ] 押せる要素は `<button>` / `<a>`（`<div onClick>` を使っていない）
- [ ] 共通の primitive は `src/components/ui/` に置いた（クラス文字列をコピペしていない）
- [ ] hex の直値を書いていない（`bg-meal` などのトークン名を使った）
- [ ] `text-[10px]` 以下を使っていない

### インタラクション

- [ ] 押せる要素に `cursor-pointer`
- [ ] 押せる要素に `active:scale-[0.98]` 系のフィードバック
- [ ] タップ領域が **44×44px 以上**
- [ ] `disabled` 状態を実装した（見た目 + `disabled` 属性 + 二重送信防止）
- [ ] 非同期処理に loading 状態がある / 300ms 未満ではスピナーを出していない

### モーション

- [ ] アニメーションしているのは `transform` と `opacity` だけ
- [ ] `transition-all` を使っていない
- [ ] duration / easing を 04-motion.md のトークンから選んだ
- [ ] 500ms を超える動きは演出枠のみ
- [ ] `prefers-reduced-motion` で止まる

### アクセシビリティ

- [ ] テキストのコントラストが **4.5:1 以上**（塗りボタンの白文字も確認した）
- [ ] `focus-visible` のリングが見える（`focus:outline-none` を単独で書いていない）
- [ ] アイコンのみのボタンに `aria-label`
- [ ] 装飾 SVG に `aria-hidden="true"`
- [ ] 入力に `<label>` が紐付いている
- [ ] エラーがテキストでも伝わる（色だけではない）
- [ ] バッジ・チップの意味が色だけに依存していない

### レイアウト

- [ ] チップ / タグ / テキストが折り返しても切れない
- [ ] 長い料理名・長い数値でレイアウトが崩れない
- [ ] 画面端固定の要素に `env(safe-area-inset-*)` を入れた
- [ ] 375 / 768 / 1024 / 1440px で確認した

## C. PR 前

```bash
npm run lint
npm run build
npm test
npm run test:e2e   # 主要動線に影響する変更のとき
```

- [ ] 上記コマンドが通る
- [ ] **キーボードだけで**主要動線を通せた
- [ ] Lighthouse の Accessibility が 95 以上
- [ ] スクリーンショットを before / after で PR に貼った
- [ ] `docs/design/` のルールから外れた箇所があるなら、**理由を PR 説明に書いた**
- [ ] トークンやルールを変えたなら、`docs/design/` 側も更新した

## D. FitMealTracker 固有の確認

- [ ] **オフラインで動く**（localStorage / IndexedDB。ネットワーク前提の UI にしていない）
- [ ] Gemini 解析の**失敗時に手入力へフォールバック**できる
- [ ] 写真が無い記録でもレイアウトが崩れない
- [ ] 記録の削除が **取り消せる**（またはきちんと確認が出る）
- [ ] PWA としてホーム画面から起動したときにも破綻しない
- [ ] `GEMINI_API_KEY` がクライアントに漏れていない（`NEXT_PUBLIC_` を付けていない）

---

## E. 3D / Three.js を触るとき（該当時のみ → 08-3d.md）

- [ ] その 3D は「機能」か「演出」か決めた（記録動線の中に WebGL を挟んでいない）
- [ ] 1 画面に `<Canvas>` が 1 つだけ
- [ ] `dynamic(..., { ssr: false })` で遅延読み込みしている
- [ ] 追加した GLB が **500KB 以下**（超えるなら Draco / meshopt 圧縮をかけた）
- [ ] `public/models/` に使わないファイルを残していない
- [ ] ライト・シャドウマップ・ポストプロセスを増やしていない（matcap + `ContactShadows` の方針を維持）
- [ ] 画面外・タブ非アクティブで `frameloop` を止めている
- [ ] `prefers-reduced-motion` でループが止まり、静止ポーズになる
- [ ] 3D にしか無い情報が無い（種目名・数値はテキストでも出ている）
- [ ] `<Canvas>` が装飾なら `aria-hidden="true"` + `tabIndex={-1}`
- [ ] WebGL 失敗時のフォールバック（`ErrorBoundary` / 静止画）がある
- [ ] 実機のモバイルでフレームレートと発熱を確認した
